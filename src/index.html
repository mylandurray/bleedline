Add Bleed — help

Adds bleed and trim marks to finished-size artwork, like Acrobat's Add Bleed. Everything runs in this page; files never leave your PC.

Using it

  1. Set the bleed and trim-mark options on the left.
  2. Drop one or more PDF, JPG or PNG files on the drop area (or click it).
  3. Each file is processed straight away and shown in the preview. Click Download to save name_bleed.pdf. Click a file in the list to preview it.
  4. Changing a setting re-processes all loaded files. A setting that isn't valid (empty, negative, or zero where it must be more) is outlined in red and nothing is processed until it's fixed.

Bleed modes

  • Mirror reflects the outer edge of the artwork outward by the bleed amount. Best for photos, gradients and textures. Note that text or logos close to the edge are mirrored into the bleed too.
  • Stretch edge takes a thin sliver from each edge (the Edge sliver width) and stretches it across the bleed. Best for flat colours and backgrounds; avoids mirrored text. Corners use the corner sliver.

Warnings

Anything that needs a check is listed in amber under the file. Read these before sending to print, especially:

  • No TrimBox: the trim is taken from crop marks on the page if there are any, otherwise the page size is used. If the file already includes bleed but has no marks, that will be wrong: use Trim size › Set size. Files that look like a standard size plus bleed are flagged. If only 7 of the 8 marks were found, the warning says so; check the trim size.
  • Too complex / more than one set of crop marks: the crop marks couldn't be read safely, so the page size is used. Set the trim by hand under Trim size › Set size.
  • Printable annotations not included: stamps, comments or filled-in form fields set to print are left out. Flatten them in Acrobat first if they should print.
  • Layers: layers are kept with the same on/off settings as the original.

Password-protected or damaged PDFs are refused rather than risk a broken output.

What you get

  • A PDF the size of trim + bleed + room for the marks. TrimBox and BleedBox are set, so imposition software and preflight pick up the trim correctly.
  • Artwork is untouched: the original page content, fonts and images are copied as they are, not rasterised or re-compressed. With Hide on-screen seams off, nothing inside the trim changes at all.
  • Output intent (PDF/X profile), XMP metadata, document info, transparency settings and layers are carried over.
  • Trim marks are drawn in registration colour (separation All, so they print on every plate including spots), outside the bleed.

Notes

  • Trim size › Auto uses the PDF's TrimBox if it has one (a TrimBox the same as the page counts as none). Otherwise it looks for printer's crop marks on the page (short lines at each corner extending the trim edges) and uses the rectangle they mark; failing that, the CropBox / page size. Page rotation is honoured. Multi-page PDFs are processed page by page. Crop marks are only trusted when it's clear-cut: at least 7 of the 8 marks, thin (1.5 pt or less), out in the margin within 25 mm of each corner, nothing drawn along the trim edges themselves (so table borders and die lines aren't mistaken for marks), and a trim covering at least half the page, roughly centred. Marks on hidden layers don't count. With crop marks plus bleed marks, the inner set is the trim. Anything doubtful (two different sets, or a page too complex to check) falls back to the page size with a warning.
  • Trim size › Set size uses the width × height you enter (as the artwork appears on screen), centred on the page or image, for every loaded file. Anything outside it, such as existing bleed or marks, is replaced by the new bleed. Switching to Set size fills in the selected file's current trim. Each time the page is opened it starts on Auto.
  • The artwork should be finished size with no bleed. If a PDF already has bleed and a TrimBox, the existing bleed is replaced.
  • Hide on-screen seams (off by default): PDF viewers draw a faint line wherever two separately cut pieces of artwork meet, so a plain bleed shows hairlines along the trim on screen (they don't print). With this on, the bleed is painted over the outer 0.26 mm of the trim with a mirror of the edge, which removes the lines; at that width it is lost in normal trimming tolerance. Untick it if the trim area must stay exactly as supplied.
  • Images are placed at the dpi saved in the file (or the dpi setting if there isn't one), turned to match the camera orientation tag, and keep their embedded colour profile. JPEG data is embedded unchanged; PNGs are embedded losslessly (greyscale, 16-bit and indexed stay as they are). PNGs with transparency are decoded to 8-bit RGB with an alpha mask, and you'll get a warning if that changes anything.
