Bleedline — help

Adds bleed and trim marks to finished-size artwork, like Acrobat's Add Bleed. Everything runs in this page; files never leave your PC.

Using it

  1. Set the bleed and trim-mark options on the left. Hover over an option for a short explanation.
  2. Drop one or more PDF, JPG or PNG files on the big drop area (or click it). Once files are loaded, drop more anywhere on the page or use + Add files.
  3. Each file is processed straight away and shown in the preview, two pages side by side (switch to 1 page above the preview; ◀ ▶ or the arrow keys turn pages). Open full view opens it in the browser's PDF viewer to zoom or print. Click Download to save name_bleed.pdf. Click a file in the list to preview it. The top bar shows the selected file's artwork size as supplied, the trim it gets, and the final size with bleed.
  4. Changing a setting re-processes all loaded files; changing a trim size re-processes only the selected file. A setting that isn't valid (empty, negative, or zero where it must be more) is outlined in red and nothing is processed until it's fixed.

Bleed modes

  • Mirror reflects the outer edge of the artwork outward by the bleed amount. Best for photos, gradients and textures. Note that text or logos close to the edge are mirrored into the bleed too.
  • Stretch takes a thin sliver from each edge (the Edge strip width) and stretches it across the bleed. Best for flat colours and backgrounds; avoids mirrored text. Corners use the corner sliver.

Warnings

Anything that needs a check is listed in amber under the file. Read these before sending to print, especially:

  • No TrimBox (or a TrimBox the same as the page, which means no trim was set): the trim is taken from crop marks on the page if there are any, otherwise the page size is used. If the file already includes bleed but has no marks, that will be wrong: use Trim size › Custom. Files that look like a standard size plus bleed are flagged. If only 7 of the 8 marks were found, the warning says so; check the trim size.
  • Too complex / more than one set of crop marks: the crop marks couldn't be read safely, so the page size is used. Set the trim by hand under Trim size › Custom.
  • Printable annotations not included: stamps, comments or filled-in form fields set to print are left out. Flatten them in Acrobat first if they should print.
  • Layers: layers are kept with the same on/off settings as the original.

Size check

Before anything is made, pages that are the same size in the file must all get the same trim. If one page would be cut to a different size (say a stray TrimBox, or crop marks found on only one page), the file is refused with a message naming the page. Check the file, or set the trim under Trim size › Custom. Pages of different sizes may have different trims. You also get a warning if the trim is much smaller than the artwork, or was found in different ways on different pages. After the PDF is made it is read back to confirm every page has the trim and bleed it should.

Password-protected or damaged PDFs are refused rather than risk a broken output. So are arithmetic-coded and 12-bit JPEGs, which most RIPs can't read: re-save them as a normal JPEG.

What you get

  • A PDF the size of trim + bleed + room for the marks. TrimBox and BleedBox are set, so imposition software and preflight pick up the trim correctly.
  • PDF page content, fonts and images are copied unchanged (byte-for-byte for single-stream pages; multi-part page content is joined and recompressed losslessly), not rasterised. Nothing inside the trim is changed, scaled or moved. PDF viewers, including the preview, can show faint lines where the bleed meets the artwork; they don't print. Hide lines in the preview (under the settings) paints the bleed 0.26 mm over the trim edge in the preview only, so they disappear on screen; the downloaded PDF is always made without it. The preview is a guide: check the downloaded PDF before it goes to print.
  • Output intent (PDF/X profile), XMP metadata, document info, transparency settings and layers are carried over. The XMP gets a new instance ID and modification date, since the output is a new file.
  • PDF/X and PDF/A files keep their claim: the output keeps the source's PDF version, and for PDF/X-1a, PDF/X-3 and PDF/A-1 it is saved without object streams or transparency. You'll get a warning to re-verify the file in Acrobat Preflight before sending it, because Bleedline can't fully check conformance itself.
  • Trim marks are drawn in registration colour (separation All, so they print on every plate including spots), at the offset you set. They may sit in the bleed, which is trimmed off, but never inside the trim.

Notes

  • Trim size › Auto uses the PDF's TrimBox if it has one (a TrimBox the same as the page counts as none). Otherwise it looks for printer's crop marks on the page (short lines at each corner extending the trim edges) and uses the rectangle they mark; failing that, the CropBox / page size. Page rotation is honoured. Multi-page PDFs are processed page by page. Crop marks are only trusted when it's clear-cut: at least 7 of the 8 marks, thin (1.5 pt or less), out in the margin within 25 mm of each corner, nothing drawn along the trim edges themselves (so table borders and die lines aren't mistaken for marks), and a trim covering at least half the page, roughly centred. Marks on hidden layers don't count. With crop marks plus bleed marks, the inner set is the trim. Anything doubtful (two different sets, or a page too complex to check) falls back to the page size with a warning.
  • Trim size › Custom uses the width × height you enter (as the artwork appears on screen), centred on the page or image. Anything outside it, such as existing bleed or marks, is replaced by the new bleed. The trim size applies to the selected file only: click a file in the list to see or change its trim. Each file keeps its own setting, and new files start on Auto. Switching to Custom fills in the selected file's current trim. Trim sizes aren't saved, so the next time the page is opened everything starts on Auto.
  • The artwork should be finished size with no bleed. If a PDF already has bleed and a TrimBox, the existing bleed is kept when there is enough of it (see below), otherwise it is replaced.
  • Keep existing bleed (on by default): when a PDF page has a real TrimBox and its artwork (BleedBox, else the page) reaches at least the bleed amount beyond the trim on all four sides, that artwork is used as the bleed, cut to the bleed size, instead of mirroring. Nothing is flipped or pieced together, so there are no seams. It isn't used when the trim comes from crop marks or Custom. If only some sides have enough, the bleed is mirrored and a warning says so.
  • Images are placed at the dpi saved in the file. If an image has none, you're asked for one under the file (filled in with the last dpi you entered). Images are turned to match the camera orientation tag, and keep their embedded colour profile. JPEG data is embedded unchanged; PNGs are embedded losslessly (greyscale, 16-bit and indexed stay as they are). PNGs with transparency are decoded to 8-bit RGB with an alpha mask, and you'll get a warning if that changes anything.
